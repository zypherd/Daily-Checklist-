# dev/ — sources for the 3D café layer

`index.html` at the repo root is the deployable, self-contained app. It is assembled by:

```bash
python3 dev/build.py
```

which takes `dev/classic_index.html` (the original 2D checklist, untouched) and injects the 3D
layer from `dev/src/`:

- `cafe3d.css`, `cafe3d.html` — 3D-mode styles and HUD markup
- `core.js` helpers · `textures.js` procedural textures · `assets.js` optional real-world asset pack (manifest, scanned-texture swaps with world-space UVs, instanced scanned models with procedural fallbacks, captured-sky blending) · `room.js` materials/room/lighting/sky · `post.js` render pipeline (CSM shadows, GTAO, bloom, sky env-map, light shafts, flare) · `exterior.js` beach resort (deck, pool, sand, ocean shader, huts, palms, towers) · `avatar.js` sculpted humanoid / the player · `npc.js` barista, beach-goers, gulls ·
  `props.js` furniture builders · `nav.js` grid + A* + collision · `cat_model.js` jointed cat +
  animation · `cat_ai.js` behaviour brain + locomotion · `world.js` layout, toys, ambient life ·
  `player.js` cameras & interaction · `audio.js` synthesized sound · `ui.js` panel/HUD glue ·
  `main.js` boot

You never need to run the build to *use* the app — only to change it. Edit a file in `dev/src/`,
run the build, and commit the regenerated `index.html`.

## The asset pack (`assets/`)

`assets/` is generated by

```bash
python3 -m pip install --user pillow numpy      # once
python3 dev/fetch_assets.py                    # needs node/npx on PATH for the model step
```

which downloads the chosen CC0 assets from Poly Haven's API, packs the skies into gamma-encoded JPGs (upper
hemisphere only, with the sun position and brightness statistics written to `assets/manifest.json`), converts the
1k texture sets to WebP, and runs `gltf-transform optimize` (Draco meshes, WebP textures) on the models. The
asset lists live at the top of the script; downloads are cached in `dev/.cache/` (git-ignored). Per-frame sky
exposure and per-model orientation fixes are tuned in `assets.js` (`SKY_EXPOSURE`, `MODEL_ADJ`), so the pack
rarely needs regenerating.
